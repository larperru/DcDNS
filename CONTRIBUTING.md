# Contributing to DcDNS

Thanks for your interest in DcDNS.

## Important license note

DcDNS is source-available under a custom license:

- Personal, non-commercial use is allowed
- Reading and auditing the source code is allowed
- **Modifying the source code is not allowed**
- **Distributing modified versions is not allowed**
- Attribution is required

Because of this, **pull requests that change the source code cannot be accepted**.

## What you can contribute

### 1. Bug reports
If something does not work, open an Issue and include:

- Windows version
- Discord version (Stable / PTB / Canary)
- DcDNS version
- What you did
- What happened
- What you expected
- Logs from the DcDNS installer if possible

### 2. Feedback
Useful feedback includes:

- Detection problems (Discord not found)
- UI issues
- Unclear README / Policy text
- Feature ideas (they may or may not be implemented)

### 3. Security / privacy notes
If you find a privacy weakness, unsafe behavior, or a broken protection, open an Issue and describe it clearly.

### 4. Translations / README improvements
Suggestions for clearer documentation are welcome.
Do not submit rewritten project files as pull requests.

## What will not be accepted

- Pull requests that modify `DcDNS.py` or other source files
- Fork-based “improved versions” intended for redistribution
- Feature PRs that change the core patching logic
- Requests to relicense the project to MIT/GPL or allow derivatives

## How to report an issue

1. Check existing Issues first
2. Open a new Issue
3. Use a clear title
4. Add steps to reproduce
5. Attach relevant screenshots or logs if needed

## Development status

DcDNS is maintained by the original author.
Features and fixes are implemented at the author’s discretion.
